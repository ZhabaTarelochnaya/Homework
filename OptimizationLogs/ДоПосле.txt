По графику видно, что gpu сильно не успевает за cpu (DXGI.WaitOnSwapChain - 70-80%). Для билда на пк стоят настройки URP-HighFidelity, для этого проекта это оверкил, можно переключить на URP-Performant.

После изменения gpu все равно не успевает за cpu. Ситуация начинает меняться с увеличением числа противников. Обновление пути ИИ в FixedUpdate выдает высокую нагрузку (до 30% при 40 агентах). Также большую часть нагрузки составляет avoidance, можно сделать его менее точным.

Смерть противников оставляет мусор, можно сделать ObjectPool.

Сравнение имен состояний через Equals() генерирует мусор. Можно использовать EqualityComparer<T>.

WaitForSeconds() оставляет мусор, можно кэшировать.

Каждый выстрел обновляет строчку в UI, оставляя мусор. С этим особо ничего не сделать.


После:
Переключение на URP-Performant: 400-290fps => 2500-555fps
AI: 20-30ms => 10-15ms

Мусор:
Фикс стейт машины: -40b каждый кадр и еще -40 каждый физический кадр.
Кэширование WaitForSeconds() в корутине обновления пути каждого агента: 
-21b * число агентов * частоту построения пути (сейчас 10) / сек.
Мусор от уничтожения противников не мерил, но теперь его тоже нет.
Основной источник мусора - обновление числа патронов в UI.
